# 🎭 트루 마스크 (True Mask)

친구들이 같은 방에 모여 질문에 **예 / 아니오**로 답하는 게임.
결과에는 **몇 명이 “예”라고 했는지만** 나오고, 누가 눌렀는지는 아무도 알 수 없습니다.

## 구조

```
truemask/
├── server/   Node.js + TypeScript + Socket.IO  (방, 코드, 투표 집계)
└── app/      React Native + Expo + TypeScript  (iOS / Android / 웹)
```

| 영역 | 기술 | 이유 |
|---|---|---|
| 앱 | React Native + Expo (TypeScript) | 코드 하나로 iOS·Android 출시, EAS로 빌드·스토어 제출 |
| 실시간 | Socket.IO | 방 입장, 투표 진행 상황, 결과 공개를 모든 폰에 바로 반영 |
| 서버 | Node.js + TypeScript | 앱과 같은 언어, 통신 타입(`protocol.ts`) 공유 |
| 결제(예정) | RevenueCat (`react-native-purchases`) | 애플·구글 인앱결제를 한 번에 처리 |

## 실행 방법

터미널 두 개를 엽니다.

```bash
cd server && npm install && npm run dev
```

```bash
cd app && npm install && npx expo start
```

- 폰에 **Expo Go** 앱을 설치하고 QR을 찍으면 바로 실행됩니다. 컴퓨터와 폰이 같은 와이파이에 있어야 합니다.
- 브라우저로 보려면 `npx expo start --web`을 실행하세요. 탭을 여러 개 열면 여러 명처럼 테스트할 수 있습니다.
- 서버 주소는 개발 중에는 자동으로 잡힙니다. 배포할 때는 `EXPO_PUBLIC_SERVER_URL=https://...`로 지정합니다.

서버 테스트:

```bash
cd server && npm test
```

## 게임 흐름

1. 닉네임과 성별을 입력합니다. 성별은 다른 사람에게 표시되지 않습니다.
2. 방장이 **모드**(혼성 / 남자만 / 여자만)와 **질문 수**(5~8)를 골라 방을 만들면 5자리 코드가 나옵니다.
3. 친구들이 코드를 입력해 입장합니다. **최소 3명**이 모여야 시작할 수 있습니다.
4. 질문마다 모두 투표하면 자동으로 결과가 공개됩니다. 방장은 “남은 사람 기다리지 않고 공개”도 할 수 있습니다.
5. 마지막에 모든 질문의 결과를 한 번에 보여주고, “한 판 더”로 새 질문을 받을 수 있습니다.

## 익명성 설계 (핵심)

- 개별 투표는 **서버 메모리에만** 있고, 결과를 공개하는 즉시 지웁니다. DB나 로그에 남기지 않습니다.
- 클라이언트에는 `yes`/`total` 숫자와 "투표했는지 여부"만 보냅니다. 무엇에 투표했는지, 누구의 성별인지는 전송하지 않습니다. 통합 테스트로 확인합니다.
- 2명이면 내 답으로 상대 답을 알 수 있으므로 **3명 미만이면 시작할 수 없고**, 게임 중 3명 미만으로 줄면 대기실로 돌아갑니다.
- 방장이 일찍 공개하는 것도 3명 이상 투표했을 때만 가능합니다.

## 유료화: 성별 공개 (프리미엄)

혼성 모드에서 방장이 잠금을 해제하면 결과에 **“예”를 누른 남자 / 여자 인원**이 추가로 표시됩니다.

- **익명 보호 장치:** 한 성별이 1명뿐인 질문은 성별 내역을 숨깁니다. 여자 1명뿐인데 “여자 1명이 예”라고 나오면 그 사람 답이 그대로 드러나기 때문입니다.
- **지금은 개발용 모의 결제입니다.** 앱은 `mock-receipt`를 보내고, 서버의 `verifyReceipt`가 이를 받아줍니다. 출시 전에 할 일은 두 가지입니다.
  1. 앱의 `src/screens/PremiumCard.tsx`에 RevenueCat 결제를 연결합니다.
  2. 서버의 `createGameServer({ verifyReceipt })`를 실제 영수증 검증으로 교체하고, 배포 환경에 `ALLOW_MOCK_PREMIUM=false`를 설정합니다.

## 질문 추가·수정

`server/src/questions.ts`에서 공통 질문과 모드별(혼성/남자/여자) 질문을 관리합니다. 서버에서 무작위로 뽑으므로 앱을 다시 배포할 필요가 없습니다.
