# 🎭 트루 마스크 (True Mask)

친구들이 같은 방에 모여 질문에 **예 / 아니오**로 답하는 게임.
결과에는 **몇 명이 “예”라고 했는지만** 나오고, 누가 눌렀는지는 아무도 알 수 없습니다.

## 구조

```
truemask/
├── app/        React Native + Expo + TypeScript  (iOS / Android / 웹)
└── supabase/   DB 스키마와 게임 로직 (Postgres 함수) + 테스트
```

| 영역 | 기술 | 이유 |
|---|---|---|
| 앱 | React Native + Expo (TypeScript) | 코드 하나로 iOS·Android 출시, EAS로 빌드·스토어 제출 |
| 백엔드 | Supabase (Postgres + RPC 함수) | 서버를 따로 운영하지 않아도 됨. 게임 규칙은 DB 함수로 실행 |
| 실시간 | Supabase Realtime | 방 상태가 바뀌면 모든 폰이 바로 새 상태를 받아옴 |
| 결제(예정) | RevenueCat + Supabase Edge Function | 애플·구글 인앱결제, 영수증은 서버에서 검증 |

## 처음 설정 (한 번만)

1. Supabase 대시보드 → **SQL Editor** → New query
2. `supabase/migrations/0001_true_mask.sql` 전체를 붙여넣고 **Run**
   - 여러 번 실행해도 안전합니다. SQL을 고친 뒤 다시 실행하면 함수가 갱신됩니다.
3. 앱 접속 정보는 `app/.env`에 있습니다 (프로젝트 URL과 **공개키(publishable)**만 넣습니다. secret 키는 넣지 마세요).

## 실행 방법

```bash
cd app && npm install && npx expo start
```

- 폰에 **Expo Go** 앱을 설치하고 QR을 찍으면 바로 실행됩니다.
- 브라우저로 보려면 `npx expo start --web`을 실행하세요. 탭을 여러 개 열면 여러 명처럼 테스트할 수 있습니다.

## 웹으로 배포 (Vercel)

친구들이 앱 설치 없이 링크만 열어서 플레이할 수 있게 웹 버전을 배포합니다.

1. https://vercel.com 에 GitHub 계정으로 가입
2. **Add New → Project** → 이 저장소 **Import**
3. **Root Directory**를 `app`으로 지정 (나머지 빌드 설정은 `app/vercel.json`에 들어 있음)
4. **Deploy** → 나오는 `https://….vercel.app` 주소를 친구들에게 공유

이후 GitHub에 코드를 올릴 때마다 Vercel이 자동으로 다시 배포합니다.

DB 로직 테스트는 로컬 Postgres가 필요합니다.

```bash
cd supabase && npm install && DATABASE_URL=postgres://postgres@localhost:5432/postgres npm test
```

## 게임 흐름

1. 닉네임과 성별을 입력합니다. 성별은 다른 사람에게 표시되지 않습니다.
2. 방장이 **질문 수**(5~8)를 골라 방을 만들면 5자리 코드가 나옵니다.
   - **모드는 고르지 않습니다.** 게임을 시작하는 순간 참가자 성별 구성으로 자동으로 정해집니다 (모두 남자 → 남자만, 모두 여자 → 여자만, 섞여 있으면 → 혼성).
   - 대기실에서 미리 보여주지 않는 이유: 누가 들어올 때마다 모드가 바뀌어 보이면 그 사람의 성별이 드러나기 때문입니다.
3. 친구들이 코드를 입력해 입장합니다. **최소 3명**이 모여야 시작할 수 있습니다.
4. 질문마다 모두 투표하면 자동으로 결과가 공개됩니다. 투표 현황은 이름 없이 같은 캐릭터로 "몇 명이 투표했는지"만 보여줍니다. 연결이 끊긴 사람은 30초 뒤 빠지고 남은 사람 투표로 공개됩니다.
5. 마지막에 모든 질문의 결과를 한 번에 보여주고, “한 판 더”로 새 질문을 받을 수 있습니다.

## 익명성 설계 (핵심)

- 앱에 들어가는 공개키는 누구나 볼 수 있는 키입니다. 그래서 게임 테이블은 API로 노출되지 않는 `truemask` 스키마에 두고 RLS로 잠갔습니다. 앱은 `public.tm_*` 함수만 호출할 수 있고, 함수는 집계 숫자만 돌려줍니다.
- 개별 투표(`truemask.votes`)는 결과를 공개하는 즉시 삭제됩니다.
- 각 참가자는 입장할 때 비밀 토큰을 받습니다. 토큰이 없으면 남의 자리로 투표할 수 없습니다.
- Realtime으로 나가는 것은 "방 상태가 바뀌었다"는 버전 숫자뿐이고, 앱은 그 신호를 받으면 함수로 새 상태를 받아옵니다.
- 위 내용은 `supabase/test`의 테스트로 확인합니다 (앱과 같은 anon 권한으로 테이블 직접 조회 시 거부되는지 등).
- 2명이면 내 답으로 상대 답을 알 수 있으므로 **3명 미만이면 시작할 수 없고**, 게임 중 3명 미만으로 줄면 대기실로 돌아갑니다.
- 방장이 일찍 공개하는 것도 3명 이상 투표했을 때만 가능합니다.

## 유료화: 성별 공개 (광고 1개 + 1회권 + 평생권)

혼성 게임에서 결과에 **“예”를 누른 남자 / 여자 인원**을 추가로 보여줍니다. 무료 공개는 없습니다.
**화면 문구와 가격 표시는 전부 `app/src/copy.ts` 한 파일에 있습니다.**

| 방법 | 가격 | 어디서 | 내용 |
|---|---|---|---|
| 보상형 광고 | 광고 1편 | 최종 결과 → 잠긴 질문 누르기 (방에 GOLD MASK가 없을 때만) | **방장이** 광고를 끝까지 보면 그 질문 1개 공개 (판마다 1번, 모두에게 보임) |
| 1회권 (소모성) | ₩1,700 | 최종 결과 (방에 GOLD MASK가 없을 때만) | 이번 판 **모든 질문** 공개. 참가자 **누구나** 살 수 있고, 켜지면 끌 수 없음. “한 판 더”를 누르면 꺼짐 |
| GOLD MASK (평생권, 비소모성) | ₩5,900 | 홈 화면 GOLD MASK 버튼 (없으면 회색, 사면 금색), 최종 결과 | 산 사람이 들어간 혼성 게임은 **처음부터 자동 공개** + 광고 제거. 방에 **한 명만 있어도 방 전체에 적용**. 평생권을 가진 사람이 가면 그림(켜짐 금색 / 꺼짐 회색)을 눌러 **끄고 켤 수 있음** |

- **게임 중에는 팔지 않습니다.** 결과 숫자 아래에 `남자 ? 여자 ?`만 흐리게 보여줍니다.
- **최종 결과:** 질문마다 `남자 ? 여자 ?` 칸을 누르면 누르면 아래에서 선택창이 올라옵니다 (방장: 광고 / 1회권 / 평생권, 다른 사람: 1회권 / 평생권). 위쪽 “이번 판 전부 보기”로도 열 수 있습니다.
- **이미 켜진 방:** 결제 칸이 사라지고 모두에게 작은 표시(`👑 이번 판 공개` / `👑 GOLD MASK`)만 보여줍니다. **누가 샀는지는 서버도 앱에 보내지 않습니다.**
- **익명 보호 장치 (광고·유료·평생권 모두 항상 적용):** 방에 남자나 여자가 1명뿐이면 성별 공개를 아예 하지 않습니다 (평생권도 안 켜짐). “예”가 1명인 건 상관없습니다. 어떤 질문에서 한 성별 투표자가 1명뿐이었다면 그 질문은 성별 내역을 숨기고 광고로도 열 수 없습니다.
- **웹:** 인앱결제와 광고는 앱에서만 됩니다. 배포된 웹에서는 “앱에서 할 수 있어요” 안내만 나옵니다 (로컬 개발 중에는 웹에서도 가짜 결제·가짜 광고로 시험 가능).
- **광고도 지금은 가짜입니다.** 5초짜리 테스트 화면(`app/src/RewardedAd.tsx`)이 끝나면 `mock-ad:<무작위>`를 서버(`tm_ad_pick`)가 받아줍니다. 출시 전에 `react-native-google-mobile-ads`의 보상형 광고로 바꾸고, AdMob 서버 확인(SSV) 콜백을 Edge Function으로 받아 확인합니다.
- **지금은 개발용 가짜 결제입니다.** 1회권은 `mock-receipt:<무작위>`(한 번 쓴 영수증은 다시 못 씀), 평생권은 `mock-lifetime`을 서버가 받아줍니다. 출시 전에 할 일:
  1. `app/src/purchases.ts`를 RevenueCat(`react-native-purchases`)으로 교체합니다. 상품 2개: 소모성(1회권), 비소모성(평생권, entitlement `lifetime`). 로그인 없이 스토어 계정 + “구매 복원”으로 평생권을 되찾습니다.
  2. 영수증과 평생권을 RevenueCat으로 검증하고 secret 키로 방을 여는 Supabase Edge Function을 만듭니다.
  3. `truemask.config` 테이블의 `allow_mock_premium`을 `false`로 바꿉니다.

## 마스코트 · 아이콘 · 로딩 화면

마스코트는 눈웃음 짓는 흰 가면입니다. 그림은 `app/src/mascotArt.ts` **한 곳**에만 있고, 앱 화면과 아이콘 PNG가 모두 이걸 씁니다.

- 첫 화면: 가면이 둥실 떠 있고 가끔 깜빡이거나 윙크합니다 (`app/src/Mascot.tsx`). 폰의 “동작 줄이기”가 켜져 있으면 멈춥니다.
- 로딩 화면: 폰이 띄우는 정지 그림(스플래시)이 사라지면 같은 자리에서 가면이 윙크하고 첫 화면으로 넘어갑니다 (`app/src/Intro.tsx`).
- 그림을 고친 뒤 아이콘을 다시 만들려면 저장소 루트에서:

```bash
node --experimental-strip-types design/export-icons.ts
```

## 질문 추가·수정

Supabase 대시보드 → Table Editor → 스키마 `truemask` → `questions` 테이블에서 추가·수정합니다. `mode`는 `common`(모든 모드), `mixed`, `male`, `female` 중 하나이고, `enabled`를 끄면 숨겨집니다. 앱을 다시 배포할 필요가 없습니다.
